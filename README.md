# CS 可视化实验室

> 计算机科学基础概念可视化探索 · 课程综合实验

## 项目简介

用 Python + Tkinter 展示计算机基础概念的计算过程，包含进制转换、补码加减、
ASCII 奇偶校验、排序可视化、进程调度与页面置换六个模块。

## 快速开始

```bash
python main.py
```

## 运行

```bash
python main.py
```

## 模块

1. 进制转换
2. 补码加减法
3. ASCII 与奇偶校验
